# Self-Driving Car Simulator (Unity Project)

These are WebGL builds of the Udacity [Self-Driving Car Simulator](https://github.com/udacity/self-driving-car-sim) from 2016. The project simulators are functionally the same as the original desktop applications except they've been reworked to replace websockets/SocketIO which doesn't work in the web browser. Instead of websockets, the WebGL builds use `console.log` to send messages that can be used from client-side JavaScript.

These build files are served via GitHub Pages by accessing `https://swatson555.github.io/self-driving-car-sim/<FILE>`.
